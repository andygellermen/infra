# Rule schemas

- `sprach-a-lyzer_rule_v0.1.json` bleibt der historische Foundation-Vertrag.
- `sprach-a-lyzer_rule_v0.2.json` bleibt der erste strikte Authoring-Vertrag.
- `sprach-a-lyzer_rule_v0.3.json` ergänzt die typisierten, nicht-scorenden
  Aktionen für Sinnauswahl und Resonanzhinweise.
- `sprach-a-lyzer_parameter_v0.1.json` begrenzt justierbare Fachparameter und
  verlangt Approval für editierbare Werte.
- `sprach-a-lyzer_policy-registry_v0.1.json` bleibt der Sprint-0A-Stand.
- `sprach-a-lyzer_policy-registry_v0.2.json` registriert die Rule-v0.3-Aktionen
  und Rule Set v0.2.

Hard Guardrails gehören nicht in editierbare Rule- oder Parameter-Sets.
