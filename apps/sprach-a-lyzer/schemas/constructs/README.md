# Construct schemas

- `sprach-a-lyzer_construct-ontology_v0.2.json` fixiert die kanonischen
  Language Features, Contextual Constructs, Working Hypotheses und optionalen
  Reflective Constructs. Das Artefakt selbst erzeugt keine Core Scores.

Runtime-Signale sind deterministische Evidenzdefinitionen. Kompositionen
benennen nur abgeleitete Pattern; Dimensionsbeiträge bleiben ausschließlich
versionierten Regeln vorbehalten.
