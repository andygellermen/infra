# Encryption & Key Model --- zurückgestellt

## Entscheidung

Die frühere Planung einer EasyPeasyMail-eigenen
E-Mail-/Content-Verschlüsselung ist für Core und MVP gestrichen.

Eine spätere Verschlüsselung kann als optionales Plugin/Capability
untersucht werden.

Für die aktuelle Security-Baseline siehe
`36-security-baseline-no-mail-encryption.md`.

Transport- und Infrastruktur-Sicherheit (TLS, Authentisierung, Secrets,
Zugriffsschutz) bleiben selbstverständlich Bestandteil der Architektur.
