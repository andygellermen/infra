# Conscious UI Wireframe

## Inbox

``` text
EasyPeasyMail                                      ⌘K

Heute

Anna Müller
Termin kommende Woche                             11:42

Thomas Berger
Rechnung September                                09:18   ◌

Newsletter · 37 neu                                ›


Gestern

Max Mustermann
Rückmeldung Projekt                               18:03
```

`◌` steht beispielhaft für „Body/Attachment nicht vollständig offline".
Keine Farbe ist für die Bedeutung zwingend erforderlich.

## Reader

``` text
←

Anna Müller
Termin kommende Woche
Heute · 11:42

Hallo Andy,

[...]



                                      Antworten
```

Sekundäraktionen erscheinen über Keyboard/Command Palette oder bewusstes
Hover/Tap.

## Composer

``` text
An:     anna@example.org
Betreff: Termin kommende Woche

# ruhiger Schreibraum

Text ...



                                     ⌘↵ Senden
```

## Conscious-Regel

Maximal drei bewusst aktivierte Erweiterungen dürfen den ruhigen
Grundmodus ergänzen. Der Nutzer entscheidet, nicht das Produkt.
