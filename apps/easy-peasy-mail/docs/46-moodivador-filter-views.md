# Moodivador Filter Views

## Idee

Die kausalen Invarianten werden nicht als technische Debug-Texte in die
normale Inbox gekippt. Sie inspirieren stattdessen sichtbare
Filter-/Status-Views.

## Conscious

Nur handlungsrelevante Abweichungen: -
`2 Nachrichten warten auf Versand` -
`1 Anhang derzeit nicht verfügbar` - `Newsletter · 37 neu`

Keine Infrastrukturdiagnostik.

## Development

Zusätzliche technische Filter: - offline cached - pending sync -
outbox/retry - attachment remote - quarantined - conflict - raw/source
available

## BurnOut

Dashboard-artige Vollsicht: - Sync Cursor - Device State - Event Lag -
Mailbox Version - Attachment Availability - Spam/Newsletter
Classification - Send Ledger Status - Ingress/Delivery Information

## Grundsatz

Moodivador verändert die **Sichtbarkeit** technischer Wahrheit, niemals
deren Semantik.
