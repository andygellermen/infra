# Newsletter & Mailing Lists

## Ziel

100 Newsletter sollen nicht 100-mal Aufmerksamkeit beanspruchen.

## Erkennung

Signale: - `List-ID` - `List-Unsubscribe` - wiederkehrende
Absender-/Domainmuster - Precedence/Header - Nutzerklassifikation -
optional statistische Klassifikation

## Darstellung

Im Conscious Mode erscheint beispielsweise nur:

``` text
NEWSLETTER                         37 neu

Heise        "KI-Regulierung in..."
GitHub       "Your weekly..."
Shop         "20 % auf..."
```

Oder noch radikaler:

``` text
Newsletter · 37 neu
```

Erst bewusster Eintritt öffnet die Sammlung.

## Regel

Newsletter sind **nicht Spam**. Bündelung ist Aufmerksamkeitssteuerung,
keine Zustellentscheidung.

## Werbung

Werbliche Inhalte innerhalb legitimer persönlicher Nachrichten
automatisch herauszuschneiden wäre riskant. Sicherer: - Tracking-Bilder
standardmäßig blockieren/proxyen. - Newsletter als Ganzes bündeln. -
Reader View anbieten. - Original jederzeit erreichbar halten.
