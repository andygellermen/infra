# Moodivador & Print Modes

## Moodivador

**Moodivador** ist der Arbeitsname für die Anzeige-/Arbeitsmodi. Der
Begriff darf ruhig spielerisch bleiben: Der Modus verändert nicht nur
Optik, sondern die Menge an Reizen, Werkzeugen und Kontext.

### Conscious

Kommunikation pur.

### Development

Text, Markdown, Header/Source bei Bedarf, Keyboard-first.

### BurnOut

Bewusstes Gegenbild: maximale Informationsdichte, Dashboard, Labels,
Ranking, Panels und klassische Power-Mail-Funktionen.

Der BurnOut Mode bleibt erhalten. Gerade der Kontrast kann sichtbar
machen, wie stark zusätzliche UI-Elemente Aufmerksamkeit beanspruchen.

## Drucken: wichtige Gegenposition

Der aktuelle Bildschirmmodus sollte **nicht automatisch das Druckbild
diktieren**. Sonst druckt BurnOut unnötig Dashboard-Chrome, Buttons und
Navigation.

Stattdessen erhält jeder Moodivador eine passende **Print Personality**:

### Conscious Print

-   Absender, Empfänger, Datum, Betreff, Body
-   Anhänge als Dateiliste
-   keine UI
-   kein Logo-Zwang
-   viel Weißraum

### Development Print

-   wie Conscious
-   optional Message-ID, technische Header, Markdown/Plaintext-Hinweis
-   Zeilen/Codeblöcke sauber

### BurnOut Print

-   Mailinhalt
-   ausgewählte Labels
-   Priorität
-   Thread-Kontext
-   Attachment-Metadaten
-   optional Auth-/Delivery-Info
-   **kein Screenshot des Dashboards**

## Print Preview

Vor jedem Druck kann zwischen `Conscious | Development | BurnOut`
gewählt werden --- unabhängig vom gerade verwendeten Bildschirmmodus.

Das erhält den charakteristischen BurnOut-Gedanken, ohne Papier mit
Navigations- und Bedienoberfläche zu verschwenden.
